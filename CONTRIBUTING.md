# Contributing

Änderungen bitte über einen eigenen Branch und Pull Request einreichen. Vor dem Pull Request muss `dotnet build SnmpMibBrowser.csproj -c Release` ohne Fehler durchlaufen. Neue Benutzertexte müssen auf Deutsch und Englisch ergänzt werden. Für SNMP-Tabellen sind die verwendeten MIB-OIDs und mindestens ein reproduzierbarer Testfall zu dokumentieren.
