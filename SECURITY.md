# Security Policy

Sicherheitsprobleme bitte nicht als öffentliche Detailbeschreibung melden. Verwenden Sie nach Veröffentlichung die private GitHub-Funktion **Report a vulnerability** im Bereich *Security Advisories* des Repositorys.

SNMP-Schreibzugriffe verändern Zielgeräte. Verwenden Sie SET nur mit ausdrücklich autorisierten Zugangsdaten.
